# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work. Harassment or
personal attacks aren't welcome in issues, pull requests or anywhere else the project lives.

Report problems privately through the maintainer's GitHub profile. Reports are kept
confidential, and the maintainer may remove comments, close threads or block accounts that
break these rules.
